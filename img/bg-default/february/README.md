# February

February has **28** days.

Drop one image per day here, named by day of month with no leading zero:

`1.png` … `28.png`

That is **28** `.png` files for this folder. Day numbers are unpadded — use `7.png`, not `07.png`. The background page resolves this folder as `img/bg-default/february/<day>.png`.

Leap year note: in a leap year February has **29** days, so an extra file is needed — `29.png` is only loaded on Feb 29 (2028, 2032, ...). The other three years out of four never request it.
